import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Flatten
from tensorflow.keras.datasets import mnist
import numpy as np

# Load and prepare the MNIST dataset
(x_train, y_train), (x_test, y_test) = mnist.load_data()



# Normalize the pixel values to be between 0 and 1
x_train, x_test = x_train / 255.0, x_test / 255.0

# Define the feedforward neural network model
model = Sequential([
# Flatten layer to transform the 28x28 image into a 1D vector of 784 pixels
Flatten(input_shape=(28, 28)),
# A hidden layer with 128 neurons and ReLU activation
Dense(128, activation='relu'),
# The output layer with 10 neurons (for digits 0-9) and Softmax activation for probabilities
Dense(10, activation='softmax')
])


# Compile the model
# Using Adam optimizer, sparse_categorical_crossentropy loss for integer labels, and accuracy as a metric
model.compile(optimizer='adam',
loss='sparse_categorical_crossentropy',
metrics=['accuracy'])

# Print a summary of the model's architecture
model.summary()

# Train the model on the training data for 5 epochs
print("\nTraining the model...")
model.fit(x_train, y_train, epochs=5)

# Evaluate the model on the test data
print("\nEvaluating the model...")
test_loss, test_acc = model.evaluate(x_test, y_test, verbose=2)
print(f'\nTest accuracy: {test_acc*100:.2f}%')
# Make predictions on the first few images of the test set
predictions = model.predict(x_test[:5])
# Print the predicted class and true class for the first image
predicted_class = np.argmax(predictions[0])
true_class = y_test[0]
print("\nPrediction for the first test image:")
print(f"Predicted class: {predicted_class}")
print(f"True class: {true_class}")

######Viva

• What are the structural differences between the MNIST and CIFAR-10 datasets?
	• Answer: MNIST contains \(28\times28\) grayscale images (1 channel) representing handwritten digits (0–9). CIFAR-10 contains \(32\times32\) color images (3 RGB channels) representing real-world objects (like airplanes, cats, and cars).
• Why did the input dimension of the Flatten layer change from 784 to 3072?
	• Answer: MNIST has \(28 \times 28 \times 1 = 784\) pixels. CIFAR-10 has three color channels, so flattening it results in \(32 \times 32 \times 3 = 3072\) input values.
• What is the purpose of y_train.flatten() in the CIFAR-10 code, and why wasn't it explicitly needed for MNIST?
	• Answer: The Keras CIFAR-10 dataset loader imports labels as a 2D column vector with the shape (50000, 1). We flatten it to a 1D vector (50000,) so it matches the format expected by the sparse_categorical_crossentropy loss function. MNIST labels are already 1D by default.

🏗️ Network Architecture & Design

• Why do both models have exactly 10 neurons in their final dense layer?
	• Answer: The final layer represents the number of target classes. Both MNIST (digits 0–9) and CIFAR-10 (10 distinct object categories) have exactly 10 output classes.
• What is the difference between the hidden layer and the output layer activations in these codes?
	• Answer: The hidden layer uses ReLU to introduce non-linearity and prevent vanishing gradients. The output layer uses Softmax to convert the raw numerical outputs (logits) into a probability distribution that sums up to 1.0.
• Why does a simple Feedforward Neural Network (Dense) yield high accuracy on MNIST but poor accuracy on CIFAR-10?
	• Answer: MNIST digits are simple, centered shapes where pixel spatial locations don't change much. CIFAR-10 features color variations, textures, and objects positioned anywhere in the frame. Flattening a complex image destroys spatial relationships, meaning a Convolutional Neural Network (CNN) is required for CIFAR-10.

⚙️ Loss Functions & Math Optimization

• Why did we choose sparse_categorical_crossentropy instead of regular categorical_crossentropy?
	• Answer: We use sparse categorical crossentropy because our dataset labels are integers (e.g., 3 or 7). If our labels were one-hot encoded vectors (e.g., [0, 0, 0, 1, 0...]), we would use standard categorical_crossentropy.
• What does np.argmax() do when parsing predictions?
	• Answer: The model outputs an array of 10 probabilities. np.argmax() finds and returns the index of the highest probability value, which corresponds directly to the predicted class label.
• What does model.summary() display, and why is it useful?
	• Answer: It displays the structural layout of the model, including the output shape of every layer, the types of layers used, and the total number of trainable and non-trainable parameters.

🚀 Performance & Training

• What is an epoch? How does it differ from a batch?
	• Answer: An epoch is one complete pass of the entire training dataset through the neural network. A batch is a small subset of the dataset (e.g., 32 samples) processed before updating the internal weights.
• What is the Adam optimizer, and why is it preferred over standard SGD?
	• Answer: Adam (Adaptive Moment Estimation) calculates adaptive learning rates for each parameter. It combines the advantages of RMSProp and Momentum, making it faster to converge and less sensitive to initial learning rate settings than standard Stochastic Gradient Descent (SGD).


1. What is a feedforward neural network?
It is a neural network in which information moves from the input through hidden layers to the output without recurrent loops.

2. What are its main components?
Input layer, hidden layers, output layer, weights, biases and activation functions.

3. What does an artificial neuron do?
It calculates a weighted sum of inputs, adds a bias and applies an activation function:
\[
y=f\left(\sum_i w_i x_i+b\right)
\]
4. What are weights and biases?
Weights control the influence of inputs. Bias shifts the neuron’s activation. Both are learned during training.

5. What is MNIST?
MNIST is a dataset of handwritten digits from 0 to 9. It contains 60,000 training images and 10,000 test images, each measuring 28 × 28 pixels in grayscale.

6. Why do we divide pixel values by 255?
It scales pixel values from 0–255 to 0–1, helping make training more stable.

7. Why do we use Flatten?
Flatten converts each 28 × 28 image into a vector of 784 values so it can enter a Dense layer. It has no trainable parameters.

8. What is a Dense layer?
It is a fully connected layer in which each neuron connects to every output of the previous layer.

9. Why do we need an activation function?
It introduces nonlinearity so the network can learn complex relationships. Without nonlinear activations, stacked Dense layers behave like one linear transformation.

10. What is ReLU?
\[
\operatorname{ReLU}(x)=\max(0,x)
\]
It returns zero for negative inputs and keeps positive inputs unchanged.

11. Why does the output layer contain 10 neurons?
MNIST has 10 possible classes: digits 0–9. Each output represents one class.

12. Why do we use Softmax?
Softmax converts output scores into class probabilities that sum to 1. The class with the highest probability is selected.

13. What is a loss function?
A loss function measures the difference between predictions and actual targets. Training tries to minimize this loss.

14. Why use sparse categorical cross-entropy?
It is suitable for multiclass classification when labels are integers such as 0, 1 and 2.

15. What is backpropagation?
Backpropagation calculates gradients of the loss with respect to weights using the chain rule. An optimizer then uses these gradients to update the weights.

16. What is SGD?
Stochastic Gradient Descent updates parameters using gradients calculated from individual examples or, commonly in practice, small batches.
\[
w_{\text{new}}=w_{\text{old}}-\eta\frac{\partial L}{\partial w}
\]
Here, \(\eta\) is the learning rate.

17. What is the learning rate?
It controls the size of weight updates. Too large a value can make training unstable; too small a value can make learning slow.

18. What is the difference between SGD and Adam?
SGD uses gradients with a chosen learning rate, optionally with momentum. Adam also maintains moving estimates of gradients and squared gradients to adapt updates for each parameter.

19. What are an epoch, batch size and iteration?
- Epoch: One complete pass through the training data.
- Batch size: Number of examples processed before an update.
- Iteration: One training step on a batch.
20. What do compile(), fit(), evaluate() and predict() do?
Method	Purpose
compile()	Configures optimizer, loss and metrics
fit()	Trains the model
evaluate()	Calculates loss and metrics on supplied data
predict()	Produces model outputs for supplied inputs


21. What is overfitting?
Overfitting happens when a model learns training-specific patterns and performs poorly on unseen data. Training loss may decrease while validation loss increases.

22. How can we reduce overfitting?
Use more representative data, dropout, L2 regularization, early stopping or a smaller model.

23. What does np.argmax() do?
It returns the index of the largest value. We use it to convert predicted probabilities into a class number.

24. How many trainable parameters are in this model?
A Dense layer has:
\[
(\text{inputs}\times\text{neurons})+\text{neurons}
\]
Therefore:
- First Dense layer: \(784\times128+128=100,480\)
- Output layer: \(128\times10+10=1,290\)
- Total: 101,770
