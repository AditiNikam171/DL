# %% [Part 1] TensorFlow: manual forward pass + gradients (eager mode)
import tensorflow as tf

x = tf.constant([[1.0, 2.0]])
W = tf.Variable([[0.5], [0.5]])
b = tf.Variable([0.1])

def forward(x):
    z = tf.matmul(x, W) + b
    return tf.nn.relu(z)

output = forward(x)
print("Output:", output.numpy())            # [[1.6]]

with tf.GradientTape() as tape:
    y = forward(x)
    loss = tf.reduce_mean(tf.square(y - 1.0))

grads = tape.gradient(loss, [W, b])
print("Gradient w.r.t. W:\n", grads[0].numpy())   # [[1.2], [2.4]]
print("Gradient w.r.t. b:", grads[1].numpy())     # [1.2]


# %% [Part 2] Keras: MNIST feed-forward network
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0

model = keras.Sequential([
    layers.Input(shape=(28, 28)),
    layers.Flatten(),
    layers.Dense(128, activation='relu'),
    layers.Dropout(0.2),
    layers.Dense(10, activation='softmax')
])

model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

model.fit(x_train, y_train, epochs=3, batch_size=32, validation_split=0.1)

test_loss, test_acc = model.evaluate(x_test, y_test)
print(f"\nTest Accuracy: {test_acc:.4f}")


# %% [Part 3] Theano (falls back to PyTensor, its maintained successor)
# Original Theano does not install on modern Python (3.10+). If `import theano`
# fails, we use PyTensor, which has the same API. Install with: pip install pytensor
import numpy as np
try:
    import theano
    import theano.tensor as T
    print("Using Theano")
except Exception:
    import pytensor as theano
    import pytensor.tensor as T
    print("Theano not available -> using PyTensor")

x = T.dmatrix('x')
W = T.dmatrix('W')
b = T.dvector('b')
z = T.dot(x, W) + b
y = T.maximum(z, 0)                 # ReLU (works in both Theano and PyTensor)
loss = T.mean((y - 1) ** 2)
grads = T.grad(loss, [W, b])        # symbolic gradients for W and b

f = theano.function(inputs=[x, W, b], outputs=y)
grad_f = theano.function(inputs=[x, W, b], outputs=grads)

x_val = np.array([[1.0, 2.0]])
W_val = np.array([[0.5], [0.5]])
b_val = np.array([0.1])

print("Output:", f(x_val, W_val, b_val))
gW, gb = grad_f(x_val, W_val, b_val)
print("Gradient w.r.t. W:\n", gW)
print("Gradient w.r.t. b:", gb)


# %% [Part 4] PyTorch: manual gradients + custom nn.Module
import torch
import torch.nn as nn
import torch.optim as optim

torch.manual_seed(0)

# Manual forward pass and gradients
x = torch.tensor([[1.0, 2.0]])
W = torch.tensor([[0.5], [0.5]], requires_grad=True)
b = torch.tensor([0.1], requires_grad=True)

z = torch.matmul(x, W) + b
y = torch.relu(z)
loss = torch.mean((y - 1.0) ** 2)
loss.backward()

print("Gradient w.r.t. W:\n", W.grad)
print("Gradient w.r.t. b:\n", b.grad)


# Custom nn.Module
class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        return torch.sigmoid(self.fc2(x))


model = SimpleNet()
optimizer = optim.SGD(model.parameters(), lr=0.01)
criterion = nn.MSELoss()

output = model(x)
loss = criterion(output, torch.tensor([[1.0]]))

optimizer.zero_grad()
loss.backward()
optimizer.step()

print("\nLoss before the optimizer step:", loss.item())

4. The Theano Code (Static Symbolic Graph)

Theano behaves completely differently from the other three. It is a symbolic library. It doesn't actually calculate anything at first—it just builds a blueprint.
• T.dmatrix('x') and T.dvector('b'): These are not numbers. They are empty placeholders (like \(x\) and \(y\) in a school algebra equation).
• grads = T.grad(loss, [W, b]): Theano computes the derivative symbolically by looking at the mathematical graph blueprint, long before any data is passed.
• theano.function(...): This is the compilation step. Theano takes your abstract algebra blueprint and compiles it into a highly optimized, fast C-code function.
• f(x_val, W_val, b_val): Only at the very end do we pass actual numeric NumPy arrays into the compiled function to get a real answer.
• try: import theano / except: import pytensor: Original Theano no longer installs on modern Python (3.10+), so the code tries Theano first and otherwise uses PyTensor, its maintained successor, which has the same API (pytensor.function, pytensor.tensor).
• T.maximum(z, 0): This is the ReLU, written with maximum so it works identically in Theano and PyTensor.
• T.grad(loss, [W, b]): Gets the gradients for both W and b, so the result matches the TensorFlow and PyTorch parts.

Group 1: Core Concepts & Mathematics

• What does ReLU stand for, and what does it mathematically do?
	• Answer: Rectified Linear Unit. It outputs the input directly if it is positive, otherwise, it outputs zero. Mathematically: \(f(x) = \max(0, x)\).
• Why do we divide the MNIST pixel values by 255.0?
	• Answer: To normalize the data [0.0, 1.0]. Neural networks learn much faster and more stably when input features are scaled to small, uniform ranges.
• What is a gradient in deep learning?
	• Answer: A vector of partial derivatives that points in the direction of the steepest increase of the loss function. We move in the opposite direction of the gradient to minimize our errors.
• What is the purpose of the Dropout layer?
	• Answer: To prevent overfitting. It randomly deactivates a fraction of neurons during training, forcing the network to learn redundant representations rather than relying too heavily on specific pathways.

Group 2: TensorFlow & Keras

• What is the purpose of tf.GradientTape in TensorFlow?
	• Answer: It acts as a digital recorder that tracks forward pass operations automatically. TensorFlow uses this recorded graph to compute gradients via reverse-mode automatic differentiation.
• What is the difference between TensorFlow and Keras?
	• Answer: TensorFlow is a low-level framework providing core tensor math operations and graph computation. Keras is a high-level API built on top of TensorFlow to make designing, compiling, and training deep learning models faster and easier.
• What does model.compile() do in Keras?
	• Answer: It configures the learning process before training starts. It defines the optimizer (how to update weights), the loss function (how to measure mistakes), and the metrics (how to evaluate performance).

Group 3: PyTorch

• What does requires_grad=True mean in PyTorch?
	• Answer: It flags a tensor so PyTorch tracks all operations performed on it. This tells the autograd engine to compute its gradient when .backward() is called.
• Why must you run optimizer.zero_grad() before calculating new gradients in PyTorch?
	• Answer: Because PyTorch accumulates (adds up) gradients on every backward pass by default. If you don't clear the old gradients, the new updates will be mathematically incorrect.
• What does loss.backward() do under the hood?
	• Answer: It computes the gradient of the loss with respect to all learnable parameters (tensors with requires_grad=True) using the calculus chain rule.

Group 4: Theano

• What makes Theano fundamentally different from PyTorch and TensorFlow 2.x?
	• Answer: Theano relies on a static symbolic graph. You define abstract mathematical equations using placeholders (T.dmatrix) rather than concrete values. Nothing is calculated until the graph is explicitly compiled into a function.
• What does theano.function do?
	• Answer: It takes the abstract symbolic mathematical graph you designed and compiles it into highly optimized machine code (C code) that can process actual NumPy array inputs.
• What is the status of Theano today?
	• Answer: Theano was officially discontinued in 2017, and its direct, actively maintained open-source successor is called PyTensor (lineage: Theano -> Theano-PyMC -> Aesara -> PyTensor).
